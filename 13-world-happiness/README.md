# World Happiness Analysis (Python)

Exploratory analysis of the World Happiness Report (2015–2019): which factors
actually track with national happiness, and how rankings shift over time.

**Notebook:** `World Happiness Analysis.ipynb` — runs clean top-to-bottom (pandas 3, seaborn 0.13).

## What was done
- Merged five years of happiness reports (158 countries in 2015)
- Built annotated correlation heatmaps across GDP, family, health, freedom, generosity, and trust
- Plotted GDP / family / health / generosity against happiness score, colored by year

## Key findings
- **GDP per capita** is the strongest correlate of happiness (**r = 0.78**)
- **Generosity** barely moves the needle (**r = 0.18**) — a good reminder to check, not assume
- **Switzerland** ranked #1 in 2015, followed by Iceland and Denmark

## Skills
Python, pandas, matplotlib/seaborn, correlation analysis, multi-year EDA
