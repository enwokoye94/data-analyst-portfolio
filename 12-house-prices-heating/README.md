# House Prices & Heating Analysis (Python)

Exploratory analysis of Ames housing data: what actually drives home sale prices,
plus heating/fuel-cost comparisons and A/B testing.

**Notebook:** `int python analysis.ipynb` — runs clean top-to-bottom (pandas 3, matplotlib 3.11, seaborn 0.13).

## What was done
- Built a full correlation heatmap across all numeric features
- Compared average sale price per decade built (line + grouped boxplot)
- Explored heating type / fuel cost relationships and ran A/B-test style comparisons

## Key findings
- **Overall quality rating** is the strongest price driver (**r = 0.79** with SalePrice)
- Above-ground living area next (**r = 0.71**), then garage capacity (**r = 0.64**)
- Median sale price in the dataset: **$163,000**

Python, pandas, matplotlib/seaborn, correlation analysis, distribution comparison
