# Data dictionary — Sales Commission Calculator

All data is **synthetic**, generated by `generate_data.py` with fixed seed 42.

## `data/deals.csv` (531 rows)

| Field | Type | Description |
|---|---|---|
| `deal_id` | string | Unique deal identifier, `D-0001` … `D-0531` |
| `rep_name` | string | Owning sales rep (12 reps) |
| `region` | string | Rep's region: West, Central, East, South |
| `quarter` | string | Fiscal quarter closed: Q1–Q4 (FY2025) |
| `product_line` | string | Core Platform · Enterprise Suite · Add-on Services |
| `deal_size` | integer | Closed-won deal value in USD |
| `new_logo` | Y/N | Y = new customer (earns the $500 spiff) |

## `data/reps.csv` (12 rows)

| Field | Type | Description |
|---|---|---|
| `rep_name` | string | Sales rep |
| `region` | string | West, Central, East, South |
| `quarterly_quota` | integer | Assigned quota per quarter in USD ($250K–$350K by seniority) |

## Derived fields (Rep Summary sheet — all formulas)

| Field | Formula logic |
|---|---|
| Revenue | `SUMIFS` of deal_size for the rep + quarter |
| Attainment % | Revenue ÷ Quota |
| Tier 1/2/3 $ | Marginal: 5% × min(rev, quota); 8% × min(rev, 1.5×quota) − quota; 12% × rev above 1.5×quota |
| Accelerator $ | 2% × revenue above 1.25× quota |
| New-logo deals | `COUNTIFS` of new_logo = "Y" for the rep + quarter |
| Spiff $ | New-logo deals × $500 |
| Total commission $ | Tier 1 + Tier 2 + Tier 3 + Accelerator + Spiff |
| Draw $ | $9,000/quarter (named range, from $3,000/month on Plan sheet) |
| Payout $ | `MAX(total commission, draw)` |
| Payout vs quota | Payout ÷ Quota |
| Band | <80% · 80–99% · 100–124% · 125–149% · ≥150% |
